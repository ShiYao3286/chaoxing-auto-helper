# 常见问题

---

## 安装

### 装了没反应，页面右下角没有面板

**刷新学习通页面。** 内容脚本只在页面加载时注入，装扩展前就开着的页面不会自动生效。

### 工具栏看不到图标

点浏览器右上角的拼图图标 🧩，找到「学习通自动学习助手」，点旁边的图钉固定到工具栏。

### 提示「清单文件缺失或不可读取」

你选的目录不对。要用 `extension/` 这一层（里面直接有 `manifest.json`），不是仓库根目录。

### 学习通页面提示「无法访问此网站」/ 扩展报错

检查 `edge://extensions/` 里扩展是否有红色错误。有的话点「错误」看详情，通常是代码语法问题或权限变更。

## 面板与刷课

### 面板不出现，但其他页面正常

面板只在**章节学习页**显示，URL 必须包含 `mycourse/studentstudy`。

其他页面（作业页 `work/dowork`、首页等）不显示面板。

### 视频不自动播放

浏览器有自动播放限制。解决方法：

1. 先在页面上手动点一次播放
2. 然后再点「开始」

扩展会接管后续的播放控制。

### 倍速设置了但没生效

有些播放器（videojs）会强制改回 1x。扩展每轮循环都会纠正一次，但如果播放器改得比循环还快，可能看起来没生效。

可以试试：

- 把「循环间隔」调小（设置 → 刷课行为 → 2000ms）
- 或者直接在页面控制台执行 `document.querySelector('video').playbackRate = 2`

### 刷课到一半停了

常见原因：

| 现象 | 原因 | 解决 |
|---|---|---|
| 状态显示「未找到下一节按钮」 | 页面结构变了，或已到最后一节 | 手动翻页，或检查是否真的到底了 |
| 状态显示「本区域无待办」一直不动 | 当前节所有任务点已完成，但没识别到下一节 | 手动点下一节 |
| 页面弹了验证码 | 学习通风控 | 手动完成验证后再点开始 |
| 长时间无响应 | 网络问题或页面卡死 | 刷新页面重来 |

### 会不会被检测到

学习通有反作弊机制，页面自身会提示"严惩刷课等作弊行为"。

**降低风险的建议**：

- 倍速 ≤ 2.0
- 不要长时间静音挂后台
- 不要一次挂几十节课
- 循环间隔不要调得太小

本项目不做任何对抗检测的处理，仅做自动化操作。**风险自负。**

## API 配置

### 「拉取模型」失败

可能原因：

1. **服务不提供 `/models` 端点** —— 很常见，直接手填模型名即可，不影响使用
2. **路径不标准** —— 在设置页「模型列表地址」里单独填正确路径
3. **Key 无效** —— 先用「测试连通」确认

### 提示 `HTTP 404`

地址错了，最常见是**少了 `/chat/completions`**。

```
❌ https://api.deepseek.com/v1
✅ https://api.deepseek.com/v1/chat/completions
```

### 提示 `HTTP 401`

Key 无效、过期，或者没填。也可能你的中转站用了别的认证头 —— 在「额外请求头」里手动指定。

### 「测试连通」通过，但「试答一题」失败

说明网络和认证没问题，但**模型没按格式返回**。常见原因：

- 模型太弱，不理解 JSON 格式要求
- 中转站偷偷换了模型
- 提示词被中转站改动了

**解决**：换个更强的模型试试，或者在「自定义提示词」里加强约束。

### 本地 Ollama 连不上

检查：

```bash
# 确认服务在跑
curl http://127.0.0.1:11434/v1/models

# 如果返回 403，需要设置环境变量允许跨域
set OLLAMA_ORIGINS=*
ollama serve
```

## 答题

### 答案填错了

先确认是"题目抓错"还是"答案算错"：

```text
设置 → 诊断 → 抓取当前页题目
```

看抓到的题干和选项：

- **题干是乱码** → 字体解码失败，开截图解题兜底
- **题干正确但答案错** → 模型的问题，换模型或改提示词

### 状态显示「文本不可靠且截图失败」

字义是：字体解码没能还原文字，视觉模型也调不通。

排查顺序：

1. 设置 → 诊断 → **检测字体反爬**，看有没有识别出可疑字体
2. 设置 → 诊断 → **截图预览**，看截图能不能生成
3. 设置 → **测试视觉接口**，看视觉模型通不通

### 一直走文本，不触发截图

「自动判断」模式下，只有文本**确实不可靠**时才截图。如果你确认文字有问题但没触发，可能：

- 字体解码的置信度阈值判断偏乐观
- 想强制走视觉 → 把触发时机改成「总是截图」

### 视觉模型报「不支持图片输入」

`deepseek-chat`、`deepseek-reasoner` 这类是**纯文本模型**，不能处理图片。

换用支持视觉的：

```
gpt-4o / gpt-4o-mini（mini 也支持图片）
qwen-vl-max / qwen-vl-plus
glm-4v-plus
claude-3-5-sonnet
gemini-1.5-pro
```

### 填空题没填进去

学习通的填空题是 UEditor 富文本，输入区在 `iframe#ueditor_N` 内部，**不是普通 textarea**。

扩展已经按正确方式处理（写 iframe 的 body）。如果还是没进去：

- 打开「调试日志」，看控制台有没有相关报错
- 可能是该版本的 UEditor 结构又变了，需要更新选择器

### 多选题只选中了一个

多选题答案需要返回**所有**正确字母：

```json
{ "num": 2, "type": "multi", "answer": ["A", "B", "C"] }
```

如果模型只返回 `["A"]`，那就是模型答得不全。换模型或加强提示词。

## 字体反爬

### 诊断显示「未检测到自定义字体」

两种情况：

- **该页面确实没有字体反爬** —— 正常
- **字体通过 CSS 变量或行内样式注入** —— 扩展的探测可能漏掉

如果题目文字确实是乱码但没检测到字体，把诊断结果发出来看看。

### 诊断检测到了字体，但解码出来还是乱码

可能原因：

1. **字体被整体替换**（不是派生自任何系统字体）→ 会退化为多字体投票，精度下降
2. **系统缺少中文字体** → 诊断里会显示「系统可用中文字体」
3. **字体文件下载失败** → 检查网络，或该字体需要登录态

**兜底方案**：开截图解题。

### 偶尔错一两个字

正常现象，尤其是形近字（要/耍、垄/重、己/已）。

因为不同字体渲染的细微差异，个别字可能落在判定边界上。

**缓解**：

- 截图解题能显著提升准确率（视觉模型看的是渲染后的真实图像）
- 或者改用「总是截图」模式

## 截图解题

### 「截图预览」显示黑图

Headless 浏览器下 `captureVisibleTab` 有时返回黑图。正常浏览器不会有这个问题。

如果正常浏览器也黑：

- 确认标签页是**可见状态**（不能最小化）
- 检查是否有弹窗遮挡

### 截图只截到了部分题目

题目比屏幕高时需要分屏。检查：

- 「最多截图张数」是不是设成了 1
- 页面上是否有遮挡（比如悬浮面板盖住了题目）

可以把面板拖到角落，或折叠起来。

### 截图里包含了无关内容

扩展会算出题目区域的精确矩形再裁剪。如果还是包含多余内容，说明页面结构不太一样，`getBoundingClientRect` 算出的区域偏大。

**临时方案**：用「总是截图」+ 调整页面缩放，让题目区域独占一屏。

## 其他

### 扩展会不会收集我的数据

**不会。**

- 所有数据都在本地 `chrome.storage.local`
- 只在你配置的 API 地址上发请求
- 没有任何遥测、统计、上报逻辑

你可以自己读源码验证（`extension/src/` 下全部是明文 JS）。

### 怎么更新

```text
edge://extensions/ → 找到扩展 → 点「重新加载」按钮
```

改了代码后必须点这个，否则还用旧版本。

### 怎么卸载

```text
edge://extensions/ → 找到扩展 → 点「移除」
```

### 支持 Chrome 吗

支持。Chrome 102+ 都行，安装方式一样（`chrome://extensions/`）。

### 代码能改吗

可以，MIT 协议。改 `extension/src/` 下的文件，然后在扩展管理页点「重新加载」。

### 发现 bug 怎么反馈

提交 Issue 时请附上：

1. 浏览器版本（`edge://version/`）
2. 扩展设置截图（**记得打码 API Key**）
3. 控制台报错（设置 → 刷课行为 → 勾选「调试日志」，然后看 F12）
4. 「诊断」页的输出结果
