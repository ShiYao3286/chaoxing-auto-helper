# 脚本版说明（油猴用户脚本）

> **同一个扩展，两种装法**：除了「加载解压缩的扩展」，现在还提供单文件油猴脚本。
> 两者共用同一份内核源码，功能一致，只有三处**能力差异**（见 §三）。
>
> 产物：`userscript/学习通自动学习助手.user.js`（约 254 KB，10 个源文件打成一个）

---

## 一、什么时候用脚本版

| 场景 | 推荐 |
|---|---|
| 只想装一次、不想管扩展目录 | ✅ 脚本版 |
| 浏览器不允许装扩展（公司电脑、学校机房） | ✅ 脚本版 |
| 需要真实截图做视觉解题 | ❌ 用扩展版 |
| 需要跨标签页保持运行状态 | ❌ 用扩展版 |
| 开发调试（改代码即时生效） | ✅ 扩展版（重新加载即可） |

## 二、安装

### 1. 装一个用户脚本管理器

任选其一（都免费）：

| 管理器 | 浏览器 |
|---|---|
| **Tampermonkey（篡改猴）** | Edge / Chrome / Firefox / Safari |
| Violentmonkey（暴力猴） | Edge / Chrome / Firefox |
| Userscripts | Safari |

Edge 装 Tampermonkey：打开 [Edge 加载项商店](https://microsoftedge.microsoft.com/addons)，搜索 `Tampermonkey`，安装。

### 2. 装脚本

**方式 A：从 Release 下载**

去 [Releases](https://github.com/ShiYao3286/chaoxing-auto-helper/releases/latest) 下载 `学习通自动学习助手.user.js`，
Tampermonkey 会自动识别并弹出安装页 → 点「安装」。

**方式 B：拖文件**

把 `.user.js` 文件直接拖进浏览器窗口，Tampermonkey 会接管。

**方式 C：本地构建**

```bash
node build/build-userscript.cjs
```

产物生成在 `userscript/学习通自动学习助手.user.js`。

### 3. 允许跨域（**必做，否则答不了题**）

首次调用答题 API 时，Tampermonkey 会弹窗：

```text
学习通自动学习助手 想要访问 api.deepseek.com
[ 拒绝 ]  [ 总是允许 ]
```

**必须点「总是允许」**，否则脚本发不出网络请求，会提示「网络请求失败（检查油猴是否已授权该域名）」。

> 原理：页面里的 `fetch` 受同源策略限制，调第三方 API 会被 CORS 拦。
> 脚本用 `GM_xmlhttpRequest` 走浏览器扩展层网络栈，不受这个限制 —— 但需要用户授权目标域名。
> 所以脚本头里写了 `@connect *`（允许任意域名），授权粒度由用户在弹窗里控制。

### 4. 配置

进任意学习通章节页 → 点 Tampermonkey 图标 → 找到「学习通自动学习助手」→ 点 **「⚙ 设置」**：

```text
① 接口地址    https://api.deepseek.com/v1/chat/completions
② API Key     sk-xxxx
③ 模型        deepseek-chat（点「拉取」从列表选，或手填）
④ 点「测试连通」→ 显示 ✅ 连通正常（123ms，模型回显 xxx）
⑤ 点「保存」
```

配置存在 `GM_setValue`（Tampermonkey 的脚本存储），与扩展版的 `chrome.storage` **互不相通** —— 两个形态各配一次。

### 5. 开始

右下角悬浮面板 → 点 **「▶ 开始」**。

## 三、与扩展版的能力差异

| 能力 | 扩展版 | 脚本版 | 说明 |
|---|---|---|---|
| 任务队列 / 任务点判定 | ✅ | ✅ | 完全一致（同一份代码） |
| 视频播放 / 倍速 / 静音 / 防暂停 | ✅ | ✅ | 完全一致 |
| 文档滚动 / 自动下一节 | ✅ | ✅ | 完全一致 |
| 章节测验抓题 / 作答 / 填写 | ✅ | ✅ | 完全一致 |
| 字体反爬解码 | ✅ | ✅ | 完全一致 |
| 提交安全网（暂存而非硬交） | ✅ | ✅ | 完全一致 |
| 视频弹题 | ✅ | ✅ | 完全一致 |
| 路由代际 / 跨帧防抢跑 | ✅ | ✅ | 实现方式不同（见下），效果一致 |
| **真实截图** | ✅ `captureVisibleTab` | ❌ | 脚本无此 API |
| **截图解题** | 真实截图 | ⚠️ 降级为「文字重绘」 | 精度较低，只画题干文字 |
| **跨标签页状态** | ✅ background 汇总 | ❌ 只在本页 | 换标签页需重新点开始 |
| **配置存储** | `chrome.storage` | `GM_setValue` | 互不相通 |
| **入口** | 工具栏图标 + 设置页 | 油猴菜单 + 页内弹窗 | |

### 跨帧协调的实现差异（效果相同）

扩展靠 background 的共享内存判断「有没有别的 frame 正在忙」。脚本没有后台，改用：

| 层 | 扩展 | 脚本 |
|---|---|---|
| 传 tabId | `sender.tab.id` | 顶层生成 uuid 写入 `<html data-cs-tabid>`，子帧同源读取 |
| 建通道 | background 的 `Map` | `BroadcastChannel('cs-bus-<tabId>')` |
| 帧标识 | `sender.frameId` | 「顶层到当前的 iframe 序号链」（`0`、`1`、`0.1`…） |
| 兜底 | — | 跨域读不到 `window.top` 时退化为单帧模式 |

## 四、常见问题

### 面板没出现

1. 确认已进到**章节学习页**（URL 含 `studentstudy`），不是课程详情页
2. 看 Tampermonkey 图标上的**数字角标**，确认脚本在这个域名下是「运行中」
3. 刷新页面

### 提示「网络请求失败（检查油猴是否已授权该域名）」

没点「总是允许」。补救：

```text
Tampermonkey 图标 → 管理面板 → 学习通自动学习助手 → 设置 → 
「已连接的域」→ 添加你的 API 域名
```

或者最简单：删掉脚本重装一次，弹授权框时点「总是允许」。

### 答题返回空 / 解析失败

1. 先点设置里的「测试连通」看通不通
2. 检查模型名是否支持该接口（视觉模型必须支持图片输入）
3. 看控制台（F12）里有没有 `[学习通助手]` 开头的报错

### 脚本和扩展能同时装吗

能，但**别在同一次刷课里同时启动** —— 两套逻辑各点一遍，可能重复操作。

建议：只留一个启动。配置也是分开的。

### 为什么脚本版视觉解题不准

脚本拿不到 `captureVisibleTab`，只能用 `renderTextToImage()` 把题干**文字**画成图片。
如果题干本身已经被字体反爬混淆成假字，画出来的图还是假字 —— 这时视觉模型也救不了。

**遇到字体反爬严重的章节，建议用扩展版。**

### 能刷多久 / 会被发现吗

见 [README 的免责声明](../README.md#免责声明)。补充两条脚本特有的：

- 脚本注入后会在 `<html>` 上打 `data-cs-booted` 标记（和扩展一样），排查问题时有用，但也意味着"可被检测"
- 脚本频率与扩展完全一致（2.5s 主循环 + `minDwellSeconds` 最低停留），不会更快

## 六、开发者：产物怎么来的

```text
extension/src/core/*.js        ← 内核（零 chrome API）
extension/src/host/host-userscript.js  ← 脚本宿主（GM_* + BroadcastChannel）
extension/src/ui/*.js          ← 面板 + 设置弹窗（与扩展共用）
extension/src/content/*.js     ← 刷课/答题逻辑（与扩展共用）
                ↓
node build/build-userscript.cjs
                ↓
userscript/学习通自动学习助手.user.js
```

构建脚本会做 **5 项校验**，任何一项失败就不产物：

1. 除宿主外不得出现 `chrome.*`
2. 头部必需项齐全（`@match` / `@grant` / `@connect`）
3. **版本号与 `manifest.json` 同源**（防止两处漂移）
4. UI 源码不得硬编码颜色（必须走 `CSTheme` 令牌）
5. 产物语法可解析

**不要直接改产物文件** —— 下次构建会被覆盖。改源码。

详见 [脚本化改造计划.md](脚本化改造计划.md) 和 [技术原理.md](技术原理.md)。
