## 三、关键决策表

| 决策 | 理由 | 影响文件 |
|---|---|---|
| 扩展而不是油猴脚本 | 用户要求可安装、能长期存活；MV3 扩展有 storage/background/权限模型 | `manifest.json`、`extension/src/*` |
| 每个 frame 注入一份 + "就近处理" | 学习通四层 iframe，单点注入拿不到深层 DOM；就近处理天然避免同一道题被处理两次 | `inject.js` 文件头注释、`manifest.json` `all_frames:true` |
| 后台汇总 busy 时必须排除自己 | 顶层问"有人忙吗"时自己刚报过 busy=true，会永远认为有人忙 → 死锁 | `background.js` `anyBusy(tabId, excludeFrameId)` |
| 答题走用户自配 API | 合规、可控、可换模型；不把 Key 交给第三方 | `inject.js`、`background.js`、`options.*` |
| 自动提交默认关闭 | 答题正确率不可控，误交=低分；用户要求"答完才提交" | `inject.js` 默认配置、`docs/改造计划.md` §13.1 |
| 完成判定读平台标记，不用进度猜 | 实测 18% 已标绿（每日限流）；进度判断会误判 | `inject.js` `readVideoTaskState`、`docs/技术原理.md` §二 |
| 锁倍速就降 1x，不硬改 | 强制 2x 时视频不播放，损失更大 | `inject.js` `trySetRate`、git `fdd946d`/`62d0d43` |
| 不自作主张切标签，先按方案 B 条件切 | 用户明确反对"擅自切"；但停在无任务点标签又永远做不完 | `inject.js` `switchToTab` 等、`docs/改造计划.md` §14 |
| 借鉴搜题酱的"结构"，不借鉴"云依赖" | 目录/队列/代际/安全网是通用工程手法；会员与上传不可接受 | `inject.js`、`docs/搜题酱架构剖析.md` |
| 任务队列只做"清单+完成度+面板"，动手仍走原 tick | 不推翻已稳定的多 frame 就近处理；降低回归风险 | `inject.js` `refreshTaskQueue` / `queueSummary` |
| 文档拆两篇：技术剖析 + 对话纪要 | 一篇讲"抄什么、为什么"，一篇讲"怎么走到这里" | `docs/搜题酱架构剖析.md`、本文 |

## 四、踩坑与修复

| # | 现象 | 根因 | 修复 | 证据 |
|---|---|---|---|---|
| 1 | 强制 2x 后视频根本不播放，进度不动 | 平台锁倍速：设 2x 后被播放器改回，甚至反制暂停；硬刚导致播不了 | `trySetRate` 设一次 → 回读验证 → 连续 2 次被改回就永久放弃，改 1x | git `fdd946d`、`62d0d43`；`inject.js` 注释 |
| 2 | 滚动滚错区域（滚到目录树/外框），任务点没动 | 顶层滚动条是页面外框，不是学习内容；顶层自己也去滚动 | 顶层不滚自己文档，滚动只交给 cards 帧 | `scripts/fix-top-scroll.cjs`、git `b9ab434` |
| 3 | 脚本擅自切标签，被用户否掉 | 早期实现把"切标签"当默认行为 | 撤掉自动切标签；后来按用户要求改成"方案 B"条件切 | `docs/改造计划.md` §14.1/14.2 |
| 4 | 面板显示"任务点待完成 1 个，需手动处理"，永久卡住 | 两条规则冲突：不切标签 + 任务点未完成不许翻页；重写时还漏了 `skipUnfinished` 退路 | 恢复 `skipUnfinished`，把情况分四类（视频没达标/题没做/文档没滚完/本页干不了） | `docs/改造计划.md` §14.1 |
| 5 | 视频才播 18% 平台就标绿，脚本却判未完成，两边打架 | ① 用 `currentTime/duration >= 0.9` 猜进度；② 平台每日限流后直接标完成 | 改为读 `aria-label="任务点已完成"` / `.ans-job-finished`，进度降为兜底；命中限流文案主动停止 | `docs/改造计划.md` §14.3；`docs/技术原理.md` §二 |
| 6 | 动画资源永远"学习中"，刷不过去 | 硬编码 90% 门槛，动画实际门槛 70% | 运行时读 `.task-condition` 的"≥ 总时长的 N%"（微课 90 / 动画 70），读不到才用 0.9 | `scripts/fix-threshold.cjs`、`tests/probe-animation.cjs` |
| 7 | 顶层一直认为"有人忙"，永远不翻页（自锁） | `anyBusy()` 把调用者自己也算进去；自己刚上报 `busy=true` | 增加 `excludeFrameId` 参数，调用方排除自己 | `background.js` §2 注释与实现 |
| 8 | 隐藏的 `#workpop` 被误判为"弹窗可见"，每轮都去点 | 学习通弹窗常驻 DOM，只是 `display:none`；只查元素存在不看可见性 | 加 `reallyVisible()`：尺寸 + `display`/`visibility`/`opacity` + 祖先链检查 | `inject.js` `reallyVisible`、`docs` 注释 |
| 9 | 字体解码后 `q.title` 变成对象，`.slice()` 报错，答题流程崩 | `decodeMany` 返回的是对象数组 `{ok,text,map,...}`，被当字符串用 | 取 `.text` 字段；加类型保护 | `docs/改造计划.md` §13.2 #1；`inject.js` 注释 |
| 10 | 判断题点"对"两次反而取消选中，答案丢了 | 学习通判断题可 toggle；直接点目标选项会取消 | 填充前先清空所有已选项，再点目标 | `docs/改造计划.md` §13.2 #3 |
| 11 | 判断题明明答了却判"漏答"，白多截一张图 | `q.num` 是字符串、API 返回数字，`!==` 比较失败 | 统一 `Number()` 比较 | `docs/改造计划.md` §13.2 #4 |
| 12 | `captureQuizImage` 截不到题目区域 | 选择器还在用旧版 `.questionLi`，实际是 `.TiMu` | 改成 `.TiMu`，并保留旧容器兜底 | `docs/改造计划.md` §13.2 #6；`inject.js` 选择器优先级 |
| 13 | 扩展加载时报语法错误 / 脚本起不来（`VIDEO_THRESHOLD` 重复声明） | 用改文件脚本反复插入同一段 `const VIDEO_THRESHOLD`，产生重复声明 | 去重，只保留一处定义；`readVideoThreshold()` 负责运行时更新 | `scripts/fix-threshold.cjs`（锚点替换）＋对话记录；⚠️ 该坑未在文档中单独留档，属回忆性记录 |
| 14 | PowerShell 改文件后中文注释变乱码 / 行尾混乱 | Windows PowerShell 写文件编码与重定向不是 UTF-8；`.cmd` 需 CRLF | 改用 Node 脚本（`scripts/fix-*.cjs`）读写 UTF-8；`.gitattributes` 固定 `eol=lf`、`*.cmd` 用 CRLF | `.gitattributes`；⚠️ `scripts/fix-*.cjs` 当前文件本身是 GBK 注释，乱码坑的残留证据 |
| 15 | 测试脚本报"扩展未加载"，注入检查全失败 | 测试用的浏览器没带 `--load-extension` / `--disable-extensions-except`，普通实例没有扩展 | 启动参数补齐；文档写明"两个参数都不能省" | `tests/README.md` §准备环境、§踩过的坑 #1 |
| 16 | 提交按钮文字匹配成「确定/确认/是」，实际弹窗是「提交」，点不到 | 旧代码正则写错；且只在测验 iframe 里找弹窗，而弹窗在顶层 | 改为跨 frame 查找 + `#popok`/`#workpop` 优先 + 文字兜底 | `scripts/fix-submit.cjs` 头注释、`docs/改造计划.md` §13.6 #1 |
