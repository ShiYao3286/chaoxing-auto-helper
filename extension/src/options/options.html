学习通自动学习助手

刷课自动完成，答题交给你的 API；文字不可靠时可用截图兜底。配置只存浏览器本地。

答题 API

OpenAI、DeepSeek、通义、中转站、Ollama 都选「OpenAI 兼容」。
填到 /v1 也可以，会自动补全成 /v1/chat/completions。 留空路径也会补全，但建议填完整。
只存在本地 chrome.storage.local，不会上传。
会请求 /models 端点列出可用模型。拉不到就直接手填模型名 —— 不影响使用。
有些中转站的 models 端点路径不同，可在此单独指定。
占位符：{{prompt}} 系统提示、{{text}} 题目 JSON、 {{full}} 二者拼接、{{model}}、{{apiKey}}。
留空则自动尝试 choices[0].message.content / answer / data 等常见位置。
答题建议 0.1 ~ 0.3。
测试用当前表单值，不需要先保存

截图解题（视觉兜底） 未启用

占位
自动判断的依据有两方面：
· 脚本侧：字体解码置信度低、题干仍是乱码、选项缺失、模型漏答题
· 模型侧：视觉模型会自评每题置信度，低于 0.6 会标记"不确定"并跳过自动提交
必须支持图片输入。普通的纯文本模型（如 deepseek-chat）不支持，会报错。
题目很长需要分屏时用。一般 1 张足够。
会发一张 1×1 测试图，验证模型接受图片输入

作答行为

建议保持关闭。开着的话答案一错就直接交卷。
另外：截图解题时若视觉模型标注「不确定」，仍会跳过自动提交，留给你复核。

刷课行为

建议 ≤2.0
文档每步滚动距离
越小越快，越小越易触发风控
